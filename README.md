# 스윙 매매 신호 4.0

기존 3.1의 A(상승 추세 눌림목), B(과매도 반등) 진입 조건을 유지하고, **저항 접근 + 모멘텀 약화 시 50% 매도**, **추세 이탈/ATR 보호 청산/최대 보유기간 도달 시 나머지 청산**을 적용합니다.

## 배포

1. 압축파일을 해제하고 `app.py`, `engine.py`, `requirements.txt`, `README.md` 네 파일을 선택합니다.
2. GitHub 저장소 `aconfessiona/swing-trading-signal`의 `main` 루트에서 `… → Upload file`을 선택합니다.
3. 파일 4개를 업로드합니다. **같은 경로의 동일 파일명을 교체하는지 확인**하고, `Commit directly to the main branch`를 선택한 뒤 `Commit changes`를 누릅니다.
4. Streamlit Community Cloud가 재배포할 때까지 기다렸다가 앱을 새로고침합니다. 진입 파일은 `app.py`입니다.

## 설계 설명

- 일봉 볼린저밴드(20,2), 40일 회귀 기반 평행 상승 채널, 전일 이전 60일 고점, 완료된 주봉의 20주 볼린저 상단과 과거 26주 고점, 최근 80일 종가 기준 거래량 집중 가격대(근사치)를 저항으로 사용합니다.
- RSI, 스토캐스틱, MACD 히스토그램으로 상승 탄력 약화를 확인합니다.
- 저항은 범위(허용 오차)로 판단하며, 신호 발생일 종가에 판단하여 **다음 거래일 시가**에 주문 체결된 것으로 가정합니다.
- 1차 매도 후 동일 포지션에서 1차 매도를 반복하지 않습니다. 잔여 물량은 추세 이탈, ATR 보호 청산 또는 최대 보유기간으로 종료합니다.
- 40일 회귀 채널은 객관화한 근사 채널이며 수동으로 그리는 피벗 추세선과 다를 수 있습니다. 거래량 집중 가격대는 실제 매물대 데이터가 아닌 **일별 종가×거래량 기반 근사치**입니다.
- 주봉 저항은 완료된 주봉의 값만 사용하며, 진행 중인 주의 미래 정보를 사용하지 않습니다.

## 주의

백테스트는 연구·교육용입니다. 거래세/슬리피지/갭/체결 불확실성과 매매 종목별 데이터 품질을 별도 검증해야 합니다. 증권사 연동 또는 자동 주문 기능은 없습니다.
