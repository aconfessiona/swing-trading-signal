## 기존 앱 업데이트

GitHub 저장소 최상위 `app.py`, `engine.py`, `requirements.txt`, `README.md`를 교체하고 main에 commit하면 Streamlit Community Cloud가 재배포합니다. **기존 앱의 Main file path는 `app.py` 그대로 유지**하세요.

## 주의

데이터는 Yahoo Finance의 수정주가(auto_adjust=True)이며 지연 또는 오류가 있을 수 있습니다. 최신 거래일 일봉은 장중 미확정일 수 있습니다. 백테스트는 종가 신호 다음 거래일 시가 거래를 가정하고 거래비용을 단순화합니다. 20거래일 최대 보유기간은 기술적 청산과 별도의 강제 청산 규칙입니다. 투자 판단 및 실제 체결을 보장하지 않습니다.
