# 스윙 매매 신호 4.1 — 균형형

연구용 Streamlit 일봉 분석 앱입니다. 증권사 연결이나 자동주문 기능이 없습니다.

## 4.1 개선점
- **매수 후보**: 넓은 사전 탐색 조건. 차트의 빈 원.
- **확정 매수 조건**: 종가 기준 추가 확인. 차트의 테두리 삼각형. 실제 체결과 다릅니다.
- **모의 체결**: 선택한 A/B 전략에서 미보유일 때 확정 조건이 발생하면 다음 거래일 시가 매수. 채운 삼각형.
- **1차 매도**: 저항 접근 + 모멘텀 약화 + 진입가 대비 최소 수익 조건을 만족하면 다음 거래일 시가에 최초 수량 50% 매도.
- **전량 청산**: ATR 보호, 추세 이탈, 최대 보유기간 중 하나가 충족되면 다음 거래일 시가에 남은 수량 전부 청산. 1차 매도 전에 보호 청산이 먼저 발생할 수도 있습니다.
- 최근 130거래일 후보/확정 조건 목록과 전체 모의 체결 기록을 분리했습니다.
- 매매 마커는 **실제 모의 체결일과 체결가격**에 표시됩니다.

## GitHub 업로드 (아이폰)
1. 기존 저장소 `swing-trading-signal`의 `main` 브랜치를 엽니다.
2. 파일 목록 위의 `...` 메뉴에서 **Upload file**을 선택합니다. 초록색 **Code** 버튼은 다운로드/복제용이며 업로드 버튼이 아닙니다.
3. `README.md`, `requirements.txt`, `app.py`, `engine.py` 네 파일을 **동일한 이름으로** 선택합니다.
4. 업로드 대상이 저장소 **최상위 폴더**인지 확인합니다. 기존 이름과 정확히 같아야 수정됩니다.
5. 아래의 `Commit changes`에 변경 설명을 입력하고 `Commit directly to the main branch`를 선택한 뒤 녹색 `Commit changes`를 누릅니다.
6. 저장소 파일 목록에 위 네 파일이 **각각 한 번만** 나타나는지 확인합니다. 기존 파일과 동일 이름이라면 파일이 중복 생성되지 않습니다.
7. Streamlit Cloud 앱을 새로고침하고, 문제가 있으면 `Manage app`에서 재부팅하거나 로그를 확인합니다.

## 주의사항
- A/B 조건과 매도 기준은 **가설**이며 백테스트로 검증되지 않은 최적화 설정입니다.
- 저항대 거래량 프로파일은 과거 종가를 가격 구간으로 묶은 근사치이지 실제 매물대 데이터가 아닙니다.
- 주봉 지표는 마지막 완료 주를 보수적으로 사용하므로 실제 확정 후 하루 이상 지연될 수 있습니다.
- 최신 일봉은 데이터 제공처에 따라 장중 미확정 값일 수 있습니다.
- 수익 조건은 신호일 종가로 검사합니다. 다음날 시가 체결에서 손실이 날 수도 있습니다.
