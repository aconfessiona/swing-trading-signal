# 스윙 매매 신호 4.0 — 수정본

일봉 기반 1~4주 스윙 전략 연구용 Streamlit 대시보드. 자동주문 및 증권사 연동 없음.

## 배포

GitHub 저장소 `main` 브랜치 최상위에 `app.py`, `engine.py`, `requirements.txt`, `README.md`를 **같은 이름으로 교체**합니다. Streamlit Community Cloud의 main file path는 `app.py`입니다. 기존 앱은 GitHub 변경을 감지해 재배포됩니다. 오류가 지속되면 Streamlit Cloud의 Manage app → Reboot app을 실행하세요.

## 전략

- A: 상승 추세의 20일선 눌림목과 단기 스토캐스틱 상향 교차
- B: 과매도 이후 반등과 중기 스토캐스틱 확인
- 1차 매도: 저항 근접 및 모멘텀 약화(또는 저항 2개 중첩) 시 보유 수량 50%
- 잔여 청산: 20일선 이탈과 모멘텀 약화, ATR 추적 보호, 또는 최대 보유기간
- 모든 신호는 종가에 확정하고 다음 거래일 시가 체결로 **가정**합니다.
- 추세 이탈/ATR/기간 만료는 1차 매도 이전에도 전량 청산할 수 있는 보호 예외입니다.

## 주의

주봉 저항은 **이전 완료 주봉**만 참조합니다. 거래량 집중 가격대는 실제 호가/매물대가 아닌 일별 종가·거래량 기반 근사치입니다. 전략 임계값은 검증된 최적값이 아니며 종목별 워크포워드 검증이 필요합니다. 수익률은 매매비용을 편도 bp로 반영한 단순 시뮬레이션입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
