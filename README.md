# 스윙 매매 신호 3.1

1~4주 스윙매매 연구용 Streamlit 앱입니다. 자동주문 기능은 없습니다.

## 구성
- `app.py`: 모바일 차트, 신호 및 백테스트 화면
- `engine.py`: 이동평균선, 볼린저밴드, 3종 슬로우 스토캐스틱, RSI, ATR 및 A/B 전략
- `requirements.txt`: 실행에 필요한 Python 패키지
- `README.md`: 안내

## 배포
GitHub 저장소 최상위 경로에 위 4개 파일을 같은 이름으로 업로드합니다.
Streamlit Community Cloud에서 기존 앱의 메인 파일 경로는 `app.py`, 브랜치는 `main`으로 설정합니다.

## 유의사항
- 종가 기준 신호이며 다음 거래일 시가 체결을 가정한 연구용 백테스트입니다.
- ATR 청산은 종가 확인 후 다음 시가 주문을 가정하며 실제 손절 체결가를 보장하지 않습니다.
- 데이터는 Yahoo Finance에 의존하며 실시간 확정 시세가 아닙니다.
- 신호 기준은 임시 연구값이며 종목별 검증이 필요합니다.
- 공개 GitHub 저장소에 계좌 정보, API 키, 개인정보를 업로드하지 마세요.
