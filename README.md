# 스윙 매매 신호 4.3 — 구조적 반등/눌림목 연구용

## 파일
- `app.py`: 아이폰·아이패드용 Streamlit 차트, 후보/확정/체결 분리
- `engine.py`: 지표, 4개 진입 패턴, 모의 백테스트
- `requirements.txt`: 설치 패키지
- `README.md`: 안내

## 설치/실행
`pip install -r requirements.txt` 후 `streamlit run app.py`

GitHub 저장소 루트의 같은 이름 네 파일을 교체하세요. Streamlit Cloud의 진입점은 `app.py`입니다.

## 매수 패턴
A: 최근 BB 하단 접근 후 양봉+거래량 반등
B: 확정된 상승 저점(2거래일 확인 지연) 이후 양봉+거래량
C: 상승 MA20 눌림 후 양봉 반등
D: 60일 박스(고저폭 <32%) 이후 양봉+거래량

후보는 위 패턴 충족과 비과열 조건. 확정은 점수>=70, 주봉 지지, 예상 손익비>=설정치. 확정이라도 보유 중이면 새 매수하지 않습니다. 모든 신호는 종가 확정 후 다음 시가에 모의 체결합니다.

## 주의
주봉/월봉 스토캐스틱은 이전 완료된 봉만 사용합니다. 월봉 20·12·12는 충분한 과거 월봉이 없으면 계산되지 않으며 가산점 0입니다. 월봉 필수조건이 아닙니다. 장기 박스는 '매집 추정'일 뿐 수급 증명이 아닙니다. 저항 목표는 60일 이전 고점/볼린저 상단 근사이며 정확한 매물대가 아닙니다. 초기 손절·ATR·추세이탈은 종가 확인 후 다음 시가 청산이므로 갭 손실이 가능합니다. 1차 매도는 저항+약화+최소 2% 수익 시 50%입니다. 나머지는 손절·추세 이탈·최대 보유기간으로 청산합니다. 수익률은 모의 계산이며 미래 성과 보장 없음.
