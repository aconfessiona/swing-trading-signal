# 스윙 매매 4.7.3 — 바닥 관심 / 지지 중첩 매수 개선

## 네 파일
`app.py`, `engine.py`, `requirements.txt`, `README.md`

## 변경점
- 하락 추세에서 BB 하단에 접근하면 **관심**으로 표시할 수 있으나 즉시 매수하지 않습니다.
- BB 하단과 장기 저점·확정 피벗 저점·과거에 확인된 추세선이 겹치면 **우선 후보**로 표시합니다.
- 우선 후보가 최근 5거래일에 존재하고 반등 확인봉·지지 유지·추가 붕괴 방지가 충족될 때만 **바닥 지지 확인 매수**를 허용합니다.
- 상승 눌림목 / 박스 하단 / 돌파 후 재지지 조건은 분리 유지합니다.
- 거래량은 가점, 스토캐스틱은 참고용. 1차 30%·2차 30% 매도 조건은 유지하며 잔여 청산 마커는 숨깁니다.
- `app.py`에 분석 엔진을 내장해 배포 버전 불일치 오류를 방지합니다.
- 가격 데이터는 종가 신호, 모의 체결은 다음 거래일 시가입니다.

**주의:** 관심 신호와 모의 체결은 다릅니다. 장기 추세선은 확인된 과거 저점으로 계산한 근사치이며, 실제 시장에서 유효한 지지선을 보장하지 않습니다. 실거래 검증은 수행하지 않았습니다.
