# 스윙 매매 4.6.0 (연구용)

## 변경
- 지지선 터치 직후 매수 대신 저점 안정화 + 전일 고가 돌파 + 20일선 회복 확인
- 상승 눌림목은 상승 중인 20·60일선과 반등 캔들 확인
- 저항 근처에서 실제 약세 캔들이 나타난 뒤 1차 30%, 추가 상승 후 2차 30%
- 최종 청산 마커와 목록은 숨김. 위험 청산은 백테스트 계산에 그대로 포함
- 스토캐스틱은 보조 차트만 표시

## 업로드 파일 이름
app.py, engine.py, requirements.txt, README.md
