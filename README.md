# 스윙 매매 신호 4.4

가격·지지저항 중심의 **연구용** Streamlit 앱입니다. 증권사 연결 및 자동 주문 기능은 없습니다.

## GitHub 업로드 (기존 파일 교체)
1. 이 폴더의 `app.py`, `engine.py`, `requirements.txt`, `README.md` 네 파일을 내려받습니다.
2. GitHub 저장소 `swing-trading-signal`의 `main` 브랜치에서 **Code 옆 `...` → Upload file**을 선택합니다.
3. 네 파일을 한 번에 선택하여 업로드합니다. **이름을 바꾸지 마세요.** 기존 파일과 같은 이름·같은 경로면 수정으로 처리됩니다.
4. 업로드 목록이 정확히 네 파일인지 확인하고, `Commit changes`를 누릅니다.
5. 저장소 루트에 위 네 파일이 각각 하나씩 있는지 확인합니다. Streamlit Cloud는 배포를 다시 시작할 수 있습니다.

## 매매 방식
- 매수 관심: 볼린저 하단, 확정 스윙 저점, 60일 저점, 확정된 두 피벗으로 만든 추세 지지, 피보나치 되돌림, 상승 눌림목, 돌파 후 지지 중 하나.
- 매수 확정: 관심 구간 + 당일 반등 양봉/아래꼬리. 거래량은 점수 가점으로만 반영.
- 매도 관심: BB 상단, 확정 스윙 고점, 이전 60일 고점, 주봉 저항 등에 접근.
- 매도 확정: 저항 + 약세 가격 반응 또는 저항 2개 중첩.
- 모의 체결: 당일 종가에 신호 판단, 다음 거래일 시가에 체결. 첫 저항에서 30%, 다음 저항에서 30%, 잔여 40%는 추세 이탈·ATR·최대 보유기간에 청산. 위험 신호가 먼저 오면 30/30 단계를 건너뛰고 잔여 전량 청산할 수 있습니다.
- 스토캐스틱 3종은 **표시만 하며 매매 조건에 사용하지 않습니다.**

## 주의
- 피벗은 우측 3개 봉이 완성되어야 확정되므로, 실제 바닥 당일을 미리 아는 신호가 아닙니다.
- 피보나치는 과거 60거래일 최고/최저를 기준으로 한 단순 근사이며, 상승 파동의 시작/끝을 정밀 추적하는 ZigZag 방식이 아닙니다.
- 추세선 상단은 최근 가격 폭을 이용한 근사치이며 정밀 회귀 채널이 아닙니다.
- 주봉 저항은 **완료된 주봉만** 반영합니다.
- 후보는 포지션과 무관한 조건 신호, 모의 체결은 실제 보유 상태를 반영한 백테스트 이벤트입니다.
- 동일 종목의 특정 저점/고점에 맞춘 과최적화를 피하기 위해 종목과 기간을 나누어 검증하세요.
