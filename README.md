# 스윙 매매 연구 앱 v4.7.0

## 핵심 변경
- 가격 국면을 상승 / 횡보 / 하락 전환 의심 / 하락 / 중립으로 분류합니다.
- 하락·하락 전환 의심·중립에서는 신규 매수 신호를 차단합니다.
- 상승 눌림목, 박스 하단+볼린저 하단, 돌파 후 재지지를 서로 다른 매수 유형으로 기록합니다.
- 20일선 3일 이탈, 전고점 돌파 실패, 신고점 돌파 후 재이탈, 주요 저점 이탈, 이동평균선 기울기 및 거래량을 하락 전환 평가에 반영합니다.
- 기존 1차·2차 30% 분할 매도 조건은 유지합니다. 잔여 청산은 차트에서 숨기지만 백테스트에서는 계속 계산합니다.
- 스토캐스틱은 매수/매도 신호 조건에 사용하지 않습니다.

## 주의
이 버전은 **국면별 진입 엔진의 첫 구현**입니다. 임의 생성 데이터에 대한 실행 테스트만 통과했으며, 실거래·실제 종목 다중 백테스트 검증을 완료한 버전이 아닙니다. 매매 신호는 종가 확정 후 평가하고 다음 거래일 시가에 모의 체결합니다. 종목별 최적화 없이 초기 임계값을 적용하므로 누락·오신호가 가능합니다.
