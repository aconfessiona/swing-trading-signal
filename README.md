# 스윙 매매 신호 프로그램 1.0

## 실행
Python 3.10 이상 설치 후 이 폴더에서:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

실행 후 터미널에 표시되는 로컬 주소(보통 http://localhost:8501)를 브라우저에서 엽니다.
동일 Wi-Fi의 휴대전화에서 접속하려면 컴퓨터의 로컬 IP와 방화벽 설정을 확인하세요. 인터넷에 공개하지 마세요.

## 데이터
- Yahoo Finance 조회: 한국 코스피 종목은 `006400.KS`처럼 `.KS`, 코스닥은 `.KQ`; 미국은 `AAPL`.
- CSV: `Date,Open,High,Low,Close,Volume` 컬럼 필수. 날짜는 YYYY-MM-DD.
- Yahoo Finance 데이터는 제공 범위/지연/정확성에 제약이 있습니다. 실제 거래 전 증권사 데이터와 대조하세요.
- 기본적으로 수정주가(auto_adjust)를 사용합니다. CSV와의 결과 차이가 있을 수 있습니다.

## 신호 및 체결 모델
- A: MA20 > MA60, MA20 상승, 최근 5일 MA10 또는 BB10 하단 부근 눌림, K5/D5 골든크로스, K10 상승, 종가 MA5 위.
- B: 최근 3일 BB10 하단 종가 이탈, 오늘 하단 복귀, K5<=30 골든크로스, K10 상승, 전일 대비 종가 상승.
- 장 마감 시 신호 확인, 다음 거래일 시가에 진입. A 우선.
- 1회 1종목만 보유, 레버리지 없음. 신호 발생일과 체결일이 다릅니다.
- 진입 손절은 A: 최근 10일 저점-0.1ATR 또는 신호종가-2ATR 중 높은 가격. B: 최근 5일 저점-0.1ATR 또는 신호종가-1.5ATR 중 높은 가격.
- 손절가가 신호 종가보다 낮아야 하며, 다음 시가가 손절가 아래이거나 1ATR 이상 갭 상승하면 진입을 취소합니다.
- A 목표 2R, B 목표 max(1R, 신호일 MA10). 당일 목표와 손절이 모두 닿으면 손절을 먼저 적용하는 보수적 가정.
- 갭으로 손절/목표를 넘어가면 당일 시가에 체결되는 것으로 가정.
- A는 10일선 이탈 또는 20일 보유, B는 단기 모멘텀 데드크로스 또는 10일 보유 시 다음 시가 청산.
- 수수료·세금·슬리피지는 거래당 편도 bp로 근사. 실제 거래시장/브로커 비용에 맞게 조정.
- 마지막 미청산 포지션은 시가평가로 최종 자산에 포함되며 완료 거래 기록에는 포함되지 않음.
