# 스윙 매매 신호 2.0

Streamlit 일봉 기반 연구용 주식 매매 신호 앱입니다. 증권사 API/자동주문 기능이 없습니다.

## 배포
기존 GitHub 저장소 최상위의 `app.py`, `engine.py`, `requirements.txt`, `README.md`를 이 파일들로 교체하고 커밋하세요. Streamlit Community Cloud는 `app.py`를 실행합니다.

## 전략
- A: 60일/20일 상승추세, 최근 5일 20일선 눌림, 5일 스토캐스틱 상향교차, 중장기 K>D
- B: 최근 5일 과매도 및 반등, 5일 스토캐스틱 상향교차, 10일 스토캐스틱 확인
- 매도: 20일선 하향 이탈 + 10일선 아래 / 고점 모멘텀 둔화 / 60일선 추세 붕괴
- 최대 보유기간: 기본 20거래일. 기술적 매도와 별개인 스윙 기간 제한입니다.

## 한계
신호는 확정된 일봉 종가 기준으로 사용해야 합니다. 데이터 제공자의 당일 바가 미확정일 수 있습니다. 백테스트는 다음 거래일 시가 체결 가정이며, 수정주가/실제 체결가 괴리 및 과최적화 위험이 있습니다. 과거 성과는 미래 성과를 보장하지 않습니다.
