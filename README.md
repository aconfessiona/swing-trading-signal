# 스윙 매매 4.5.0 — 신호 품질 및 모바일 차트 정리

- 이전 4.4.x는 단일 지지선 터치만으로 반복 매수하고 하락장에서 손절·재진입이 반복되는 문제가 있었습니다.
- 매수 확정은 상승 추세 눌림목, 돌파 후 재지지, 또는 복수 지지선+반전 구조로 강화했습니다.
- 청산 후 12거래일 재진입 대기; 1차/2차 분할매도는 각각 최소 +2.5%/+5% 수익 구간에서 저항 반응이 있어야 합니다.
- 보호 손절, 추적 손절, 추세 이탈, 최대 보유기간은 수익 구간이 아니어도 청산할 수 있습니다.
- 기본 차트는 **매매 마커를 표시하지 않음**. 선택 메뉴에서 거래 하나를 고르면 해당 봉만 강조; 전체 마커는 선택적으로 표시.
- 종가 신호, 다음 거래일 시가 모의 체결; 연구용, 실거래 없음.
- 과거 바닥/고점에 맞춘 사후 최적화가 아니며 수익성은 별도 검증이 필요합니다.
